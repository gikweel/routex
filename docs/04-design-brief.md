# Design Brief: GeoPulse AI

## Visual Identity

GeoPulse AI is styled with a **precision cyber-cartographic aesthetic**: dark-mode first, ultra-legible, utilitarian yet elevated with luminous emerald (`#10b981`), electric cyan (`#06b6d4`), and warning amber (`#f59e0b`) accents.

### Color System
- Background: `#0b0f17` (near-black navy)
- Surface: `neutral-900` / `neutral-800`
- Primary accent: emerald-500
- Secondary: cyan-500
- Danger / offline: amber-500
- Text: slate-100 / neutral-400

### Typography
- Clean unboxed wordmark ("GeoPulse")
- Mono for status indicators
- No decorative AI slop; strict top-bar contract

### Components
- Map canvas (Leaflet) full-bleed under chrome
- Chat drawer for grounded assistant
- Tabs: Map, Routes, Alerts, Dashboard, Security, Specs
- High-contrast mode toggle for WCAG 2.2 AA

### Motion
- Subtle transitions via motion library; prefer clarity over flourish
